# Mer3y-Hsbox · 官方更新发布

本仓库只用于发布程序更新、校验文件和更新说明。源码仓库保持私有。

## 下载

[打开最新正式版本](https://github.com/Mer3y1338/Mer3y-Hsbox-Updates/releases/latest)

每个正式版本包含 Windows x64 本体 ZIP、同名 SHA-256 文件和 release-manifest.json。没有正式版本时请等待维护者完成发布。

## 自动更新提醒

- 从 0.3.215 起，软件每次启动后只在后台检查一次。
- 不定时轮询，失败不自动重试；设置 → 关于可手动检查。
- 同一版本只主动提醒一次；不会强制暂停脚本、自动覆盖安装或重启。
- 发布新版本后，已经运行的软件不会收到定时推送；下次启动时检查。
- 普通用户无需登录 GitHub，也无需提供 Token。客户端只读取公开版本信息，不上传账号、授权或牌局数据。

## 更新方法

1. 退出脚本后下载最新 ZIP，并核对同名 SHA-256 文件。
2. 更新完整本体文件，不要只替换 EXE。保留自己的 Runtime、账号/授权、设置和日志。
3. 本体自带 .NET 8；新机器仍需按软件使用说明准备必要前置组件。
4. 0.3.214 及更早版本需要手动安装包含提醒功能的新版本一次。

分发包保留必要的可编辑运行预设和第三方许可证，但不包含私有工程、Git 历史、发布凭据或用户数据。请遵守相关组件的许可证和软件使用条款。
