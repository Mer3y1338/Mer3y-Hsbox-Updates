# Mer3y-Hsbox · 官方更新发布

源码仓库保持私有，本仓库仅提供更新公告和公开下载入口。

## 下载

[查看最新正式版本](https://github.com/Mer3y1338/Mer3y-Hsbox-Updates/releases/latest)

**后续 Release 只上传一个附件：下载链接.txt。** 实际本体 ZIP 放在夸克网盘，下载入口同时写在该版本的更新说明中。请选择与版本号对应的安装包。

历史 v0.3.215 保留原来的 ZIP、SHA-256 和发布清单，不删除、不覆盖。

## 自动提醒

- 软件每次启动后只检查一次，不定时轮询，失败不自动重试。设置 → 关于可手动检查。
- 同一版本只主动提醒一次，不强制暂停、下载、覆盖安装或重启。
- 已发布的 0.3.215 客户端只识别 ZIP 附件。老用户需手动安装一次后续兼容版本，才能识别仅包含下载链接的 Release。
- 用户不需要 GitHub Token；客户端只读取官方公开更新信息，不上传账号、授权或牌局数据。

## 更新注意

退出脚本后更新完整本体文件，不要只替换 EXE；保留自己的 Runtime、账号/授权、设置和日志。新机器仍需按软件说明准备必要前置组件。

维护者须先将对应版本上传到网盘，再发布 GitHub 公告。GitHub 发布流程不代传或验证网盘里的安装包，也不把云端重建包的哈希冒充为网盘文件哈希。
